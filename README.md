# ✈️ AeroStruct – Airport Management System

A simple Airport Management System developed using **C++17, Data Structures, and Object-Oriented Programming**.

## 📌 Features

- ✈️ Flight Management
- 👤 Passenger Management
- 🎫 Check-in & Boarding
- 🚨 Priority Passenger Handling
- 🧳 Baggage Management
- 🗺️ Airport Route Management
- 🔍 Flight Searching & Sorting
- ↩️ Undo Operations
- 💾 File Handling

## 🧠 Data Structures Used

| Data Structure | Application |
|---|---|
| Linked List | Passenger & Baggage Records |
| Array | Flight Records |
| Queue | Check-in & Boarding |
| Priority Queue | Emergency / VIP Passengers |
| Stack | Undo Operations |
| Graph | Airport Routes |
